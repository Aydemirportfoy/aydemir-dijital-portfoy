1. ZIP içindeki tüm dosyaları package.json bulunan proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-detail-gallery-mobile-note.cjs
4. npm.cmd run build
5. npm.cmd run dev

Yapılanlar:
- Portföy detayındaki fotoğraf geçişleri masaüstü ve mobilde premium animasyonlu hale gelir.
- Mobilde Portföy alanı sola hizalanır.
- Müşteriye not alanı mobilde daha kompakt ve karta uyumlu görünür.
- Supabase işlemi yoktur.
