1. ZIP içindeki tüm dosyaları proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-selected-card-premium.cjs
4. npm.cmd run build
5. npm.cmd run dev

Yapılanlar:
- Çarpı işareti artık alt satıra düşmez.
- Sil butonu sağda küçük, cam görünümlü ve premium olur.
- Kart yüksekliği küçülür.
- Numara, fotoğraf, ilan bilgisi ve sil butonu tek satırda kalır.
- Mobil ve bilgisayarda aynı düzen kullanılır.
- Sürükleme animasyonu bozulmaz.
- Supabase işlemi yoktur.
