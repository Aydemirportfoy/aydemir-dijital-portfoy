1. ZIP içindeki tüm dosyaları package.json bulunan proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-mobile-card-drag-fix.cjs
4. npm.cmd run build
5. npm.cmd run dev

Yapılanlar:
- Mobil sunum kartlarındaki yazılar sola hizalanır.
- Mobil sürükleme daha hızlı başlar.
- Kart basılı tutulduğunda turuncu vurguyla hazır olduğunu gösterir.
- Sürükleme aktif olduğunda sayfanın kayması engellenir.
- Sürüklenen kartın kaldırılma animasyonu güçlendirilir.
- Supabase işlemi yoktur.
