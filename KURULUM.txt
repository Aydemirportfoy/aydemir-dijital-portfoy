1. ZIP içindeki dosyaları package.json bulunan proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-more-menu-stack-fix.cjs
4. npm.cmd run build
5. npm.cmd run dev

Yapılanlar:
- Diğer menüsü alttaki kartın arkasında kalmaz.
- Açık menü en üst katmanda görünür.
- Mobilde menü açıldığında kartlar arasında yeterli alan oluşur.
- Supabase işlemi yoktur.
