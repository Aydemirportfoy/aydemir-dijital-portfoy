1. ZIP içindeki tüm dosyaları package.json bulunan proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-live-slide-reorder.cjs
4. npm.cmd run build
5. npm.cmd run dev

Bu sürüm:
- Sürüklenen gerçek kart kendi üzerinde hareket eder.
- Kart aşağı inerken alttaki ilan anında yumuşakça yukarı kayar.
- Kart yukarı çıkarken üstteki ilan anında yumuşakça aşağı kayar.
- Sıralama görsel olarak sürükleme sırasında değişir.
- Bırakınca yeni sıra kaydedilir.
- Sağ tarafta kopya kart veya ikinci animasyon göstermez.
- Bilgisayar ve mobilde aynı davranışı kullanır.
- Supabase işlemi yoktur.
