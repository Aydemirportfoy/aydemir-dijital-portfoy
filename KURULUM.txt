1. ZIP içindeki dosyaları proje klasörüne kopyalayın.
2. Terminalde Ctrl + C yapın.
3. node .\apply-v2-apple-detail-size.cjs
4. npm.cmd run build
5. npm.cmd run dev

Yapılanlar:
- Yüzde 70'lik küçük görünüm kaldırılır.
- Masaüstünde yaklaşık yüzde 82 genişlikte dengeli görünür.
- Fotoğraf ve bilgi paneli Apple tarzında kontrollü büyüklüğe gelir.
- Liquid glass, radius ve gölgeler sade tutulur.
- Fotoğraf üstünde yalnızca Komisyonsuz yazar.
- Alttaki Komisyonsuz Firma Satışı bilgisi değişmez.
- Telefonda tek sütun, doğal ve kolay kullanım korunur.
- Supabase verileri değiştirilmez.
